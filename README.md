# Kleinian Group Limit Set Renderer

A project exploring Kleinian Group Limit Sets and the beautiful images they produce.

Goals of the project:

- Use good practices for C++ tooling
- Solidify knowledge of C++ syntax and file structure

1. Background mathematics:
Riemann Sphere: $\mathbb{C} \cup  \infty$
Mobius Transfomations: $f(z)=\frac{az+b}{cz+d}$ where $a,b,c,d\in\mathbb C$ and $ad - bc \neq 0$

It has a matrix representation:
$$
M_f = 
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
$$

Composition of mobius maps cooresponds to matrix multiplication in the group $SL(2,\mathbb{C})/{\pm I}$.

2. A Kleinian Group, $\Gamma$, is a discrete subgroup of $SL(2,\mathbb{C})/{\pm I}$

Gamma will be generated by certain elements, and any element of gamma can be seen as a word in the generators

Let $\Gamma$ be a Kleinian group and let $z\in\widehat{\mathbb C}$

Consider the orbit of $z$

The limit set


The Limit Set, $\Lambda(\Gamma)$, captures the accumulation behavior of the group action.


For non-elementary Kleinian groups, the limit set has several important properties:

- it is closed;
- it is invariant under the group, $g(\Lambda(\Gamma))=\Lambda(\Gamma)$
- it has no isolated points;
- it is the smallest nonempty closed subset of the Riemann sphere invariant under the group;
- it can often have complicated fractal geometry.

Domain of discontinuity is the compliment of the limit set.

The limit set is an infinite group, so you have to estimate it using a finite number of group words.


This outline of the math suggests this software hierarchy:
Mobius:
- evaluate transofrmation at a point
- matrix-like composition and inverses
- normalization since invariant action under scalar multiplication
- computing fixed points

Kleinian group:
- representation of the group via generators
- making generators inverses available
- generatoring finite set of reduced group words with cooresponding Mobius transformations
